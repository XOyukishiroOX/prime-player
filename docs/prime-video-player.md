# PrimeVideoPlayer 1.1.0

状态：**正式发布**。

本版仅支持 HP Prime G1 的 2025-09-15 固件及项目既有的
BackdoorInstaller/msd 环境，不支持 G2。解码器继续固定使用
`phoboslab/pl_mpeg` 提交 `c871f2be022ece7ef4f64230b4fb8e1fb9eb6023`，
生产环境不增加运行依赖。

## 媒体与显示

- `.M1V` 必须是 MPEG-1 Video elementary stream；支持八种 MPEG-1 标准
  帧率代码：`24000/1001`、24、25、`30000/1001`、30、50、
  `60000/1001` 和 60。
- M1V 分辨率不再固定为 320×240。播放器按 16×16 宏块补齐后精算三组
  YUV420 参考帧和解码器结构，并在启动解码前检查 32 MiB 原生地址窗口。
- 输出始终是 320×240 RGB8888。适应和填充会考虑 MPEG 像素宽高比；
  原始模式居中裁剪，拉伸模式铺满屏幕。
- 320×240 原尺寸走 2×2 色度复用快速转换；其他尺寸走预计算几何参数的
  最近邻路径。
- 不支持音频、MPEG-PS、MPEG-2、MP4 或 H.264。

无法分配精确 arena 或额外 256 KiB 安全余量时，播放器会完整释放资源、
恢复屏幕，并显示本地化的“内存不足”和原始诊断码；不会自动降级或重试
另一条路径。

## 按键

- 文件列表：上下选择，`ENTER` 播放，`HELP` 打开设置，`ESC` 退出。
- 设置页：上下选择，左右修改，`ENTER` 保存并回读验证，`ESC` 放弃。
- 播放：`ENTER` 暂停/继续，左右切换文件，`ESC` 返回列表，`HELP` 临时
  切换信息叠层。临时叠层不会改写设置中的默认值。
- 定位：上下进入并以 0.1% 调整，左右以 5% 调整，`ENTER` 应用，`ESC`
  取消。M1V 从安全的序列头/I 帧锚点重新解码。

## 设置

默认值是简体中文、深色、适应、进度叠层、单次返回和同步优先。

- 语言：简体中文 / English
- 主题：深色 / 浅色
- 缩放：适应 / 原始 / 填充 / 拉伸
- 信息叠层：关闭 / 进度 / 详细
- 播完行为：单次返回 / 单曲循环 / 列表循环
- 高帧率策略：同步优先 / 完整帧优先

设置保存在严格、版本化且不超过 1024 字节的
`prime_video_settings.dat`。写入后立即回读；损坏文件会明确提示用户选择
重置或退出，不会静默覆盖。

## 高帧率策略

同步优先始终完整解码依赖帧；当帧截止时间已过时，只跳过该帧的 RGB
转换和屏幕提交。完整帧优先转换并显示每一帧，性能不足时允许慢于源时间。
完整帧优先遇到慢帧后会平移播放时间线，不再通过缩短后续帧间隔追赶旧
时间线。时钟保留源帧率的精确有理数，并分别统计解码、显示、跳过显示和
迟到帧；只有成功提交到屏幕且本帧“解码＋转换＋提交＋叠层”耗时达到
50 ms 的帧才计入 `late`。

进度和详细叠层会在画面右上角显示最近约 0.5 秒窗口内实际成功显示的
`FPS`；暂停和定位时显示 `FPS:0.0`，关闭叠层时一并隐藏。进度叠层与 FPS
直接绘制在当前视频帧上，不再铺设不透明底块；详细信息面板仍保留底色。
暂停、定位或切换叠层时，播放器先重绘当前视频帧，以清除旧的透明文字。
50/60 FPS 只承诺正确识别、解码、控制和统计，不承诺每帧实时显示。

## 视频转换器 V5

发布目录另附 `Prime_MPEG1_Batch_Converter_V5.zip`。它会按源帧率映射到
Prime 友好的 MPEG-1 标准帧率，保持宽高比、限制到最大 320×240、生成
偶数尺寸的 YUV420P `.m1v`，并继续使用约两秒 GOP 和无 B 帧设置。

检测到可初始化的 NVIDIA CUDA 设备时，可以选择 CUDA 解码；缩放、低通
和 MPEG-1 编码仍由 CPU 完成。CUDA 解码失败会明确列为失败文件，不会
静默改用 CPU 重试；也可用 `-DecodeMode CPU` 强制软件解码。
